# LLM and Generative AI Practicals

This section contains hands-on practicals and experiments covering Large Language Models (LLMs), Transformers, Retrieval-Augmented Generation (RAG), and Parameter-Efficient Fine-Tuning (PEFT).

## Topics Covered

- Transformer and GPT-2 Fundamentals
- Hugging Face Transformers
- Tokenization and Text Generation
- Attention Mechanism (Query, Key, Value)
- Retrieval-Augmented Generation (RAG)
- Document Loading and Chunking
- Embeddings and Vector Database (ChromaDB)
- Semantic Search and Retrieval
- LoRA Fine-Tuning using PEFT
- Model Training and Evaluation
